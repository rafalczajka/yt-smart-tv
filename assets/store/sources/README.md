# Store Screenshot Sources

The three store screenshots are `../screenshot-1.png`, `../screenshot-2.png`, and
`../screenshot-3.png`. Each is a 1280 x 800, 24-bit RGB PNG without transparency.

## Source Captures

All product interfaces are real browser screenshots captured from the production
build of YouTube Smart TV. The final compositions crop and scale these captures
without redesigning the product UI.

- `player.png`: YouTube player showing Spring at 6:30, captured November 3, 2026.
- `tv-code.png`: YouTube's phone-pairing screen, captured November 3, 2026. The
  displayed code was temporary and is not intended to be used for pairing.
- `options-controls.png` and `options-behavior.png`: settings sections captured
  November 5, 2026 with enlarged browser rendering. Footers and version numbers
  are excluded.
